# Changelog

All notable changes will be documented in this file. The project follows
[Semantic Versioning](https://semver.org/) after its first public release.

## [Unreleased]

### Added

- Standalone signed-in repository, package metadata, contribution and security policies.
- Cross-platform continuous integration and npm trusted-publishing workflow.
- Release-readiness and publish-artifact verification.

### Changed

- Documentation now presents signed-in as a general-purpose open-source project rather than a
  component of another infrastructure workspace.

### Fixed

- GitHub sign-in requests workflow authority so repository management can create and update GitHub
  Actions definitions.
